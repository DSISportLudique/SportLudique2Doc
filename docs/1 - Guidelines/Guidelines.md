# Guidelines

## Schémas
Les fichiers image(png) et drawio(xml) sont rangés dans docs/assets.  
Ils sont implémentés de la sorte:
```
# Schéma <sujet>
![](chemin relatif de docs/qlq/fichier.md vers docs/assets)
```

## Commandes
### Comment
Les commandes sont mises soit entre  `` ` `` pour les commandes uniques, soit entre `` ``` `` pour les blocs  

### Notations
Les notations sont définies dans un fichier: docs/'1 - Guidelines'/Notations.md dont un lien est fait en début de page utilisant des notations nécessaires (par ex les notations `>` et `]`)
