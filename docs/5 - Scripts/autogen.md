# Autogen
[autogen](https://github.com/DSISportLudique/Scripts/blob/main/autogen)

## Description
Abstraction pour la génération de certificats

## Utilisation
./autogen host-dns-name ssh-host  
host-dns-name: le hostname (www pour www.blois.sportludique.fr)  
ssh-host: informations de connexion SSH de PKI vers le serveur (user@ip ou HOST définie dans ~/.ssh/config)
